# Ebooks gratuitos — Semana 02

- **C# documentation: Strings and string literals** — capítulo oficial sobre `string`, interpolación, raw literals y `StringBuilder`. [learn.microsoft.com/dotnet/csharp/programming-guide/strings](https://learn.microsoft.com/dotnet/csharp/programming-guide/strings/)
- **.NET Fundamentals: Collections and Data Structures** — guía oficial para elegir colección, complejidad y thread-safety. [learn.microsoft.com/dotnet/standard/collections](https://learn.microsoft.com/dotnet/standard/collections/)
- **Globalization and localization in .NET** — cultura, `CultureInfo`, ICU y modo invariante. [learn.microsoft.com/dotnet/core/extensions/globalization](https://learn.microsoft.com/dotnet/core/extensions/globalization)
- **C# Language Specification (ECMA-334) — §15 Methods, §12.6 Overload resolution** — reglas exactas de paso de parámetros y resolución de sobrecarga. [ecma-international.org/publications-and-standards/standards/ecma-334](https://ecma-international.org/publications-and-standards/standards/ecma-334/)
- **Pro .NET Memory Management (capítulo 1 gratuito) — Konrad Kokosa** — layout de objetos, arrays y strings en el heap; base de las semanas 11–12. [prodotnetmemory.com](https://prodotnetmemory.com/)
