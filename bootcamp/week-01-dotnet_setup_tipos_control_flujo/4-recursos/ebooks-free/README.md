# Ebooks gratuitos — Semana 01

- **C# documentation (Microsoft Learn)** — la referencia oficial, descargable en PDF por sección. [learn.microsoft.com/dotnet/csharp](https://learn.microsoft.com/dotnet/csharp/)
- **.NET in a Nutshell: fundamentos de .NET** — tour del ecosistema en la documentación oficial: [learn.microsoft.com/dotnet/fundamentals](https://learn.microsoft.com/dotnet/fundamentals/)
- **C# Language Specification (ECMA-334)** — especificación formal; útil para consultar reglas exactas de conversiones y precedencia. [ecma-international.org/publications-and-standards/standards/ecma-334](https://ecma-international.org/publications-and-standards/standards/ecma-334/)
- **The C# Player's Guide (capítulos de muestra)** — RB Whitaker; los primeros capítulos son gratuitos. [csharpplayersguide.com](https://csharpplayersguide.com/)
- **Programming C# 12 — O'Reilly (capítulo 1 gratuito)** — Ian Griffiths; el capítulo introductorio explica el ecosistema. [oreilly.com](https://www.oreilly.com/library/view/programming-c-12/9781098158354/)
