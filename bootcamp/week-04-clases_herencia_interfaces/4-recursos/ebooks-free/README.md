# Ebooks gratuitos — Semana 04

- **Object-Oriented Programming in C# (guía oficial completa)** — clases, objetos, herencia, polimorfismo e interfaces con ejemplos ejecutables. [learn.microsoft.com/dotnet/csharp/fundamentals/object-oriented](https://learn.microsoft.com/dotnet/csharp/fundamentals/object-oriented/)
- **Framework Design Guidelines — Type Design y Member Design** — las reglas con las que se diseñó la propia BCL: cuándo clase, cuándo interfaz, cuándo sellar. [learn.microsoft.com/dotnet/standard/design-guidelines](https://learn.microsoft.com/dotnet/standard/design-guidelines/)
- **C# Language Specification (ECMA-334) — §15 Classes, §18 Interfaces** — el texto normativo sobre herencia, miembros virtuales y resolución de interfaces. [ecma-international.org/publications-and-standards/standards/ecma-334](https://ecma-international.org/publications-and-standards/standards/ecma-334/)
- **Pro .NET Memory Management (capítulo gratuito) — Konrad Kokosa** — layout de objetos, encabezado, method table y coste real de una instancia. [prodotnetmemory.com](https://prodotnetmemory.com/)
- **.NET Application Architecture Guides (eBooks gratuitos de Microsoft)** — capítulos de diseño de dominio donde se ve composición, interfaces y SOLID aplicados. [learn.microsoft.com/dotnet/architecture](https://learn.microsoft.com/dotnet/architecture/)
